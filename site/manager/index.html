This browser cannot talk to the FM-1. It has no Web MIDI. Open this page in Chrome or Edge on a computer.

THE CABINET

What an FM-1 running EVILGENIUS keeps: its projects and MY PRESETS. Save them to a file, put a file back, move presets between units. It needs Chrome or Edge on a computer (Web MIDI) and the FM-1's USB cable. Nothing is installed, and nothing leaves this computer.

1 CONNECT

Plug the FM-1 into this computer with a USB data cable and switch it on. Close other tabs and apps that use MIDI. The browser asks once for permission to use MIDI devices: allow it. Bluetooth is not used here.

No FM-1 yet.

2 BACK UP AND RESTORE

A backup is the FM-1's whole store in one .egbak file: every project and all of MY PRESETS. Restoring a backup replaces everything in the store with what the file holds. Stop the FM-1 before either, and leave it alone until it is done.

RESTORE THIS?

    Everything on the FM-1 now is replaced: its projects and MY PRESETS. It takes up to a minute. Do not unplug the FM-1 while it writes.

    3 MY PRESETS

    A preset travels as a small .egsnd file, or several in one .egsnds file. Imported presets go into the free places of MY PRESETS; nothing there is replaced.

    IMPORT THESE?

      This EVILGENIUS takes presets only as part of its store. So the page reads the store, saves it to your downloads as a backup, adds the presets, and writes the store back: the same as a restore, about a minute in all. Stop the FM-1 first; anything on it not yet saved is lost. Do not unplug the FM-1 while it writes.
